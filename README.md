### Авторизации пользоватей
Для работы с профилями необходимо в папке models создать класс User.php.
В этом классе нужно определить функцию Authorisation(), в которой будет реализован функционал авторизации.

### Маршрутизация (класс Route)
Класс `Route` (`kernel/Route.php`) обрабатывает адресную строку, определяет контроллер и экшен и запускает их. Запуск выполняется в ядре через `WCO::RunKernel()`.

#### Свойства
| Свойство | Тип | Описание |
|---|---|---|
| `$controller_name` | string | Имя контроллера (по умолчанию `SiteController`). |
| `$action_name` | string | Имя экшена (по умолчанию `index`). |
| `$docRoot` | string|null | Корень директории (`DOCUMENT_ROOT`). |
| `$serverUri` | string|null | Адресная строка запроса (`REQUEST_URI`). |
| `$getOption` | string|null | GET-параметр `option`. |
| `$getAction` | string|null | GET-параметр `action`. |
| `$controller_path` | string|null | Путь к файлу контроллера. |
| `CONTROLLER_DEFAULT` | string | Контроллер по умолчанию. |
| `$link_document` | string|null | Путь к корню директории модулей сайта. |

#### Методы
| Метод | Доступ | Описание |
|---|---|---|
| `__construct()` | public | Фильтрует входные данные, получает URI и подключает конфигурацию домена. |
| `run()` | public | Запускает контроллер и запрашиваемый экшен. |
| `loadContriller()` | private | Определяет контроллер и экшен из URI и подключает файл контроллера. |
| `ErrorPage404($controller)` | private | Выводит ошибку 404 «страница не найдена». |
| `getUri()` | private | Получает адрес и обрабатывает запросы для перенаправления. |
| `Filtr()` | private | Фильтрует входные данные (`DOCUMENT_ROOT`, `REQUEST_URI`, GET). |
| `LoadModules()` | private | Подключает модуль к пути контроллера. |
| `ParserUriModules()` | static | Парсер первого параметра адресной строки (имя модуля). |
| `getModules()` | private | Проверяет наличие папки модуля. |
| `searchUrlValue($param)` | private | Возвращает значение параметра или `index`. |

#### Формат адресной строки
Контроллер и экшен задаются в адресной строке:
- `/?option=<имя контроллера>&action=<имя экшена>` — через GET-параметры.
- `/<контроллер>/<экшен>` — через сегменты пути.
- `/<модуль>/<контроллер>/<экшен>` — для модулей.

Если контроллер не найден, подгружается контроллер по умолчанию.
